# Security Policy

## Scope

`impatient-programming` is a specification and document-guard repository containing Markdown texts (`README.md`, `MANIFESTO.md`, `PRACTICE.md`, `docs/*.md`), a local Rust verification test suite (`tests/`), and a Python codepoint scanner (`scripts/codepoint_scan.py`). No runtime binary, network service, or third-party JavaScript is shipped.

## Reporting a Vulnerability

If you discover a security issue in the GitHub Actions workflows (`.github/workflows/`) or verification scripts, please report it privately through [GitHub Security Advisories](https://github.com/david-engelmann/impatient-programming/security/advisories/new) rather than opening a public issue.
